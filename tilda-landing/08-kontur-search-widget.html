Поиск по базе закупок

Контур.Закупки

Виджет открывает поиск на стороне Контур.Закупки. iStockLink не заменяет агрегатор — собирает данные из Контур, Seldon и других источников и помогает вести тендеры в отделе. Нужен только поиск без команды — используйте виджет; нужен процесс для отдела — запросите демо платформы.

Для торговых компаний с тендерным отделом: покажем, как закупки из Контур попадают в воронку и как руководитель видит нагрузку специалистов.
