# Сценарий промо-ролика istock.link

**Формат:** 16:9, сайт  
**Хронометраж:** ~45–50 сек  
**Музыка:** cinematic corporate trap, **110 BPM**, тяжёлые 808, резкие snare/claps, motivational brass  
**Монтаж:** короткие кадры UI ↔ фразы на тёмном/фирменном фоне; смена на долю / акцент snare

---

## Принцип

| Тип кадра | Длительность | Что на экране |
|-----------|--------------|---------------|
| **Фраза** | 1.5–2.5 сек | Крупный текст + короткий подзаголовок |
| **UI** | 2.5–3.5 сек | Обезличенный экран интерфейса, лёгкий zoom/pan |
| Стык | на snare / 808 hit | Hard cut или короткий whoosh |

Паттерн: **фраза → UI → фраза → UI…** (не наоборот в основной части).

## Затравка (стиль «Закупки без хаоса.»)

Короткие хуки для интро — выбрать 2–3, бить на акцент:

1. **Закупки без хаоса.**
2. **Спрос — под контролем.**
3. **Поставщики — на виду.**
4. **От заявки до склада.**
5. **Один контур. Весь цикл.**
6. **Решения — быстрее переписки.**
7. **Закупка как система.**

Рекомендуемые связки: `1 → 4 → 5` или `1 → 2 → 7`.

## Раскадровка монтажа (для редактора)

```
[INTRO dark]  фраза 1
     CUT→    UI потребности          (punch)
     CUT→    фраза 2
     CUT→    UI согласование         (snare)
     CUT→    фраза 3
     CUT→    UI запросы/сравнение    (claps)
     CUT→    фраза 4
     CUT→    UI товары               (808)
     CUT→    фраза 5
     CUT→    UI поставщики (2 cut)   (brass)
     CUT→    фраза 6
     CUT→    UI приёмка              (hats)
     CUT→    фраза 7
     CUT→    UI тендеры              (DROP)
[OUTRO]      лого + фраза 8
```

**Правила:**
- Не держать UI дольше 3.5 сек без cut  
- На snare/clap — смена кадра  
- На 808 drop (основная секция) — самый «богатый» UI (тендеры или сравнение)  
- Текст появляется с лёгким punch-scale (95%→100%), уходит hard cut
