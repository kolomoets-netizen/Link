## Контекст продукта (факт)

- iStockLink уже имеет **приличный CRM-контур** (не только SRM/закупки).
- Типичный процесс торговой компании (согласованный черновик слайда):  
  **Лид → КП клиенту → Сделка → Заявка на закупку → Запрос поставщикам → Сравнение КП → Поставка → Отгрузка клиенту**
- На этапе «Лид» источник может быть **компания-заказчик** или **тендер**; в Link есть интеграции с агрегаторами и ЭТП. Процесс этапов не меняется — меняются возможности на входе.
- Слайд покрытия процесса (черновик v3):  
  - файл: ветка `cursor/crm-srm-business-plan-4090` → `content/business/slide-process-coverage.html` + `.pptx`  
  - сравнение зон: iStockLink (весь контур) / Битрикс из коробки / Битрикс + доработки / amoCRM  
  - строка «Битрикс + плагины» сознательно убрана

## Согласованная рабочая гипотеза позиционирования

**Не** позиционироваться как «ещё одна универсальная CRM вместо Битрикс/amo».

**Категория:** платформа продаж и закупок для торговой компании — **CRM + SRM в одном контуре**.

**Формула (черновик):**  
> iStockLink — система, в которой лид (клиент или тендер) доходит до закупки и отгрузки без разрыва между CRM и снабжением.

| Слой | Роль | Сообщение |
|------|------|-----------|
| Главная | Зонтик платформы | Продажи + закупки в одном процессе |
| Страница модуля CRM | Продуктовая страница модуля | Возможности CRM, для кого, vs Битрикс/amo, связка с SRM |
| `/trading` | Рекламная посадочная (Директ) | Можно сохранить под performance; органика и меню → модуль CRM |

URL модуля (предложение): `/crm` или `/vozmozhnosti/crm` — **не** копировать `/trading` один в один.

## Что менять на главной (направление)

Не превращать главную в CRM-лендинг. Добавить мост:

1. Hero / подзаголовок — второй контур: от сделки/тендера до поставки (не только «−30% на закупках»).
2. Меню «Возможности» — пункт **CRM** рядом с SRM и ЭТП.
3. Блок возможностей — три столпа: **CRM · SRM · ЭТП/интеграции**.
4. Один экран процесса (линия этапов) с зонами CRM и SRM.
5. CTA «Запросить демо» — демо платформы; на модуле CRM можно уточнять аудиторию.

## Структура страницы модуля CRM (черновик)

Цель: объяснить модуль, SEO, прогрев до демо — **без** ядра из офферов «за 1 день / −50%».

1. Заголовок модуля + для кого (торговая / тендерный отдел / смешанные продажи).  
2. Задачи, которые закрывает (лид = компания или тендер, воронка, задачи, связка с закупкой).  
3. Возможности по блокам — **ждём список от заказчика**.  
4. Сравнение с Битрикс / amo / «CRM + кастом».  
5. Связь с SRM: после сделки начинается закупка без выгрузки в Excel.  
6. Скрин/UI + CTA на демо / тарифы.  
7. Кому не подходит (чтобы не обещать универсальную CRM).

- Назвать продукт просто «CRM» → сравнение с Битрикс по чек-листу «почта, телефония, маркетинг».
